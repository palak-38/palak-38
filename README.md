### 🚀 Things I've built

- **[job_digest](https://github.com/palak-38/job_digest)** — a FastAPI backend that runs unattended twice a day: pulls fresh postings from the Adzuna API, scores each one for relevance with an LLM, tailors my resume to the good ones, and emails me a digest with the tailored PDFs attached. Basically a tiny job-hunting agent that works while I sleep.
- **[task_manager_api](https://github.com/palak-38/task_manager_api)** — an AI task manager built on FastAPI + Groq tool-calling, with local JSON persistence. A clean, minimal take on letting an LLM actually *do* things instead of just talk about them.
- **[Mars_Super_Resolution](https://github.com/palak-38/Mars_Super_Resolution)** — a CNN approach to memory-efficient super-resolution on high-resolution imagery.
- **[Behavior-Simulation-Challenge](https://github.com/palak-38/Behavior-Simulation-Challenge)** — my team's solution to Adobe's Behavior Simulation Challenge (Inter-IIT 2024 selection).
